# Language files

English and Hindi strings live in `src/i18n.ts`. The Hindi is a draft and needs
review by a native speaker.

Placeholders for the state's own languages:

| File | Language |
| --- | --- |
| `kha.json` | Khasi |
| `grt.json` | Garo |
| `pbv.json` | Pnar |

Safety-critical messages (risk levels, Car Mode voice alerts, the disclaimer)
must be translated and checked by native speakers. Do not machine-translate
them into production.
